## 📋 Про проєкт

**LocalSquash** — браузерний сервіс для стиснення та конвертації відео, зображень та аудіо без завантаження файлів на сервер. Вся обробка відбувається локально на пристрої користувача через FFmpeg WebAssembly.

🔗 **Досліджуваний сервіс:** [localsquash.com](https://localsquash.com/)  
🌐 **SRS-сторінка:** [GitHub Pages](https://artimanjustice.github.io/localsquash-srs/)

## 🛠️ Технології сервісу

- **FFmpeg.wasm** — обробка медіа в браузері
- **WebAssembly** — продуктивність, близька до нативної
- **H.264/AVC** — відео-кодування з налаштуванням CRF
- **100% клієнтська обробка** — файли не покидають пристрій
